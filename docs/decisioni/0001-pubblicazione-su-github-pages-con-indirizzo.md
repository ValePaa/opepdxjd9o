# 0001 — Pubblicazione su GitHub Pages con indirizzo casuale
**Data:** 2026-10-30

## Contesto
Valerio vuole la scheda online, da aprire dal telefono. GitHub Pages gratuito pubblica solo da
repository pubblici, e la pagina contiene suoi dati di salute presi da Forma (FC, VO2max, ore di
sonno). Alternative: togliere i dati prima di pubblicare, oppure pubblicare tutto.

## Decisione
Si pubblica tutto, per scelta di Valerio, sull'account ValePaa, in un repository dal nome casuale
(`opepdxjd9o`), con `noindex` nella pagina perché i motori di ricerca non la indicizzino.

## Conseguenze
L'indirizzo non si indovina, ma non è segreto: il repository pubblico compare nel profilo
github.com/ValePaa e il suo contenuto è leggibile da chi lo apre. Il diario delle serie resta nel
browser di chi usa la pagina e non va mai nel repository.
